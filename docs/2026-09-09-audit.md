## P0

1. **`http://campwatch.dev/` serves the full site over plain HTTP.** 200, no redirect, no HSTS header. Fix: Cloudflare "Always Use HTTPS" + `Strict-Transport-Security`. 10 min.
2. **Adding a campground can silently delete it on the next save.** `hooks/use-user-campgrounds.ts` never refreshes after `WATCHLIST_CHANGED_EVENT`; the add dialog uses its own hook instance, the page's `siteConfig` goes stale, and the Configure dialog's full-list PUT drops the new campground. Also keeps the onboarding empty state on screen after the first add. Fix: subscribe the hook to the event and refresh, or lift to a provider. 15-60 min.
3. **Failed email send is recorded as sent.** `notifier/check.ts:1110-1113` pushes `mergedState` even when Resend throws, so the opening enters the 24h cooldown and is never retried. Push is skipped too (same try block). Fix: skip the state update for that user on failure, retry 429/5xx once. 15 min.
4. **Notifier-state PUT has no retry; one 502 duplicates every alert that tick.** `check.ts:1119-1132`. Fix: retry 3x with backoff; longer term write per-user state via the bound KV directly. 20-45 min.

## P1 (fix today)

### Notifier
5. `findConsecutiveAvailableRanges` (`next/src/lib/recgov/match-detection.ts:40`) skips ahead greedily, so restricted `validStartDays` miss real openings (verified: Fri/Sat/Sun open, 2 nights, Saturday-only start yields zero matches). Fix `i++`, add regression test. 20 min.
6. Adjacent-group alerts never clear the 15-min lead-time gate for non-curators (`check.ts:920-935`): group age is derived from site signatures that never match, so `age` is always 0. Fix: track group keys in the first-seen map directly. 30 min.
7. Cache misses and no-data campgrounds are silent (`fetch-jobs.ts:155-165`, `check.ts:338-341`). A 90-min rec.gov block logs "0 new matches" with no hint. Fix: log misses per tick and a per-user breakdown (computed / scope-filtered / blackout / held / deduped / new). 20 min.
8. `HEARTBEAT_URL` is wired in code but not set as a secret on `campwatch-notifier`, so a dead cron alerts nobody. Fix: healthchecks.io check + `printf '%s' url | wrangler secret put HEARTBEAT_URL`. 15 min.
9. Any exception in the fast-lane fetch aborts the whole tick including notify (`check.ts:1241-1248`, no try/catch; `worker-kv.ts:27-30` unguarded). Fix: catch per item, wrap the fast lane. 10 min.
10. No fetch has a timeout (rec.gov, Resend, admin API). Fix: `AbortSignal.timeout(8000)` / `5000`. 10 min.

### API / lib
11. Any signed-in user can DoS the notifier with an oversized watchlist or `name` (`api/users/me/campgrounds/route.ts:45-59`, `api/me/route.ts:33`): elements are unvalidated, `notification-targets` serialises every user into one body fetched every minute. Fix: zod schema with caps + body size cap. 60 min.
12. Notifier's `lastNotifiedAt` write clobbers concurrent user profile edits (KV RMW across colos, `api/admin/notifier-state/route.ts:85-91`). A user disabling notifications can have it silently re-enabled. Fix: move `lastNotifiedAt` to a notifier-owned key. 45 min.
13. Unauthenticated rec.gov proxies with no rate limit (`api/campgrounds/*`, anonymous `/api/availability` rebuilt per request). Abuse gets the CampWatch UA blocked. Fix: one CF rate-limit rule, cache the anonymous snapshot, require session on `sites`/`site-details`. 40 min.

### Client
14. Greeting hydration mismatch (`dashboard/greeting/greeting.tsx`): `new Date()` in render, server is UTC, so evening Mountain users get a console error and a visible text flip every load. Fix: compute in effect. 15 min.
15. PushNudge hydration mismatch + banner flash for already-subscribed users (`push-nudge.tsx:15-26`, `use-push-subscription.ts:18-34`). Fix: mounted flag + `"checking"` status. 20 min.
16. Expired session shows the "Welcome aboard" empty state to an existing user; a transient 5xx does the same and "Use the curator's picks" then overwrites the list (`page.tsx`, `use-user-campgrounds.ts:70-72`). Fix: client auth gate like the account page; keep last-good record on GET failure. 15 min.
17. Dashboard is a two-hop waterfall (`/api/availability` waits on `/api/users/me/campgrounds`) and statically imports `SiteConfigDialog` (dnd-kit + cmdk, ~146 KB) for a closed dialog. Fix: `enabled: true`, `next/dynamic`. 15 min.

### Live site
18. No security headers at all (CSP, HSTS, frame-ancestors, Referrer-Policy, Permissions-Policy, nosniff); `X-Powered-By: Next.js` leaks. Fix: `headers()` in `next.config` (CSP report-only first). 30 min.
19. `og:image` / `twitter:image` 404 (`/og-default.png`), so every share card is blank. Fix: add the PNG or `app/opengraph-image.tsx`. 15 min.
20. `/discover` CLS 0.43 (Poor): main shifts twice, nav and footer jump as data fills in post-hydration. Fix: SSR the banner, fixed-height skeletons, `min-height` on data regions. 60 min.
21. `/_next/static/*` ships `max-age=0, must-revalidate`; a homepage-to-discover navigation revalidated 21 files. Fix: `public, max-age=31536000, immutable` on static assets. 15 min.
22. `<Link>` prefetch of `/auth/google/start` follows the 302 into Google and throws 2 CORS console errors per `/discover` load. Fix: `prefetch={false}` or plain `<a>`. 10 min.
23. Mobile perf 72 / LCP 6.7 s simulated. 10 fonts preloaded (426 KB); Geist Variable (69 KB) and Inter (48 KB) are loaded but used by no rendered text. Fix: drop both, preload only hero faces. 30 min.
24. Homepage semantics: no `<main>`/`<header>`, 8 unlabeled sections, campground input has no label and no `<form>`, two href-less anchors. 20 min.
25. Contrast: mustard on forest-deep 3.37:1 (FAQ, Lighthouse's only a11y fail); `--cw-ink-faint` (30% ink) used as text at 9-11 px in trip cards, timeline, mini calendar (~1.9:1). Fix: lighter mustard on dark sections, add a `--cw-ink-muted` token. 30 min.

### CI / infra
26. Deploy does not gate on CI; `deploy-notifier` runs `npm install` with no typecheck or tests before deploying the cron Worker. Fix: `needs:` CI job (or `workflow_run`), `npm ci` + `typecheck` + `test`, post-deploy smoke `curl -f /api/stats`. 30 min.
